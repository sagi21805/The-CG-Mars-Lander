# The-CG-Mars-Lander

## Cloning

This repository uses a git submodules. Clone it together with its submodules:

```sh
git clone --recurse-submodules https://github.com/sagi21805/The-CG-Mars-Lander.git
```

If you already cloned without `--recurse-submodules`, run:

```sh
git submodule update --init --recursive
```
